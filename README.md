# TechSphere – Tech Blog Website

## About the Project
TechSphere is a beginner-friendly technology blog website developed using HTML, CSS and JavaScript.

Users can register, log in, create technology blogs and view published blogs.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Features
- Home Page
- User Registration
- User Login
- Dashboard
- Create and Publish Blogs
- Display Published Blogs

## Project Structure
- index.html – Home Page
- login.html – Login Page
- register.html – Registration Page
- dashboard.html – Dashboard
- create-blog.html – Create Blog Page
- style.css – Website Styling
- script.js – JavaScript Functionality

## How to Run
1. Download or clone the repository.
2. Open the TechSphere folder in VS Code.
3. Open index.html in a browser.
